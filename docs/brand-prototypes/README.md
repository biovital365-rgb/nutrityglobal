# Prototipos de marca Nutrity Global

**Estado:** el **Prototipo B — N Ruta Clara** fue aprobado como dirección conceptual el 18 de septiembre de 2026. El Prototipo A queda archivado como control de fidelidad. Ningún archivo de esta carpeta es todavía el logotipo maestro ni debe sustituir automáticamente los activos de producción.

## Prototipo A — Conservación óptica

Preserva la variante recibida con la “y” amarilla. El siguiente refinamiento debe reconstruir el wordmark como vector, corregir espaciado y curvas, ampliar la legibilidad de “GLOBAL” y producir versiones monocromática y negativa.

## Prototipo B — N Ruta Clara

Explora un isotipo derivado de la N. Tres pausas internas sugieren pasos y el nodo amarillo funciona como llegada o siguiente acción. El gesto es intencionalmente discreto; debe probarse con usuarios para descartar lecturas de gráfica financiera, escalera o señal clínica.

## Decisión adoptada

Desarrollar B como sistema de diferenciación digital. A se conserva únicamente como referencia del wordmark original. La familia inicial del símbolo aprobado conceptualmente se encuentra en `approved/` e incluye color, monocroma, negativa, versiones micro y una prueba de escalas. La versión completamente verde continúa como referencia monocromática del wordmark.

La prueba inicial establece una regla provisional: usar el símbolo completo desde 48 px; entre 16 y 32 px utilizar la variante micro, sin pasos internos y con el nodo de color reforzado. Esta regla deberá confirmarse en navegadores y dispositivos reales.

- Los colores muestreados son aproximados y no sustituyen una especificación maestra.
- La validación de marca registrada y disponibilidad legal es un trabajo independiente.
